# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Confirmed React, TypeScript, Vite, browser LP solver, Vitest, plain CSS; GitHub Pages.
## Users
Produce distributors making dispatch decisions; hackathon judges evaluating the simulation.
## Product Purpose
Allocate perishable batches under capacity, demand, cost and shelf-life constraints, compare a FEFO baseline and explore disruptions.
## Capabilities and Constraints
100-minute build budget. Browser-only, deterministic calculations, labeled synthetic data and JSON import. No live market data, actual fleet routing, server, account system or model training. Display only calculated results and explicit assumptions.
## Evidence on Hand
Problem statement supplied. No organizer dataset; demonstration data is synthetic. Operational performance has not been validated.
## Product Principles
Constraint compliance; honest comparisons; transparent accounting; actionable explanations; deployable reproducibility.
